# Discordianism: Open Questions Explored (v2.32): δ-D2 exactly, and the census by module class

*v2.31 derived the v2 axioms in Lean. For the dendriform completions (δ-D2) it proved only sufficiency: each stratum is
present under a class hypothesis on the fold. This round makes δ-D2 exact and takes it to the census.*
- *In any unital algebra, each stratum is present **iff** an explicit condition on the fold holds (Lean,
  `Exact.lean`).*
- *A fold is multiplicative iff its kernel is a two-sided module over its image. So v2's δ-D2 family is exactly the
  family of M3 projections.*
- *Every fold orbit of 21 stored censuses is classified by these conditions. The polynomial growth of the orbit
  counts splits cleanly by class, and matches the families of Theorems 2–4.*
- *The extra completions, points outside the predicted strata, are explained orbit by orbit by which typed products
  vanish (confirmed on every orbit of the five censuses tested so far).*

*Audit: 73 results, all on Lean's standard axioms (one on none). v2.31's figure "65" should have read 66. One entry
(`calendar`) depends on no axioms, and that count had missed it; corrected there.*

## 1. Exact δ-D2

Write `x = p_x + n_x` with `p_x = Px` and `n_x = x − Px`, and fix `x ≺ y = x·P(y)`. Each completion family is a line
or point in b-space. For an *arbitrary* fold, Lean computes the three dendriform defects of each family:

| family | D1 | D2 | D3 |
|---|---|---|---|
| line 1 (`s`) | 0 | `−s·n_x·P(n_y p_z)` | `−s·n_x·P(n_y p_z)` |
| point 0 | `−x·P(n_y p_z)` | 0 | 0 |
| point B | `−x·P(p_y n_z)` | `x·P(n_y p_z)` | (not needed) |
| line 2 (`t`) | `−x·(P(n_y p_z) + P(p_y n_z))` | | |
| line 0 (`c`) | `−x·P(n_y p_z)` | `c·n_x·P(n_y p_z)` | `c·P(n_x p_y)·n_z − c·n_x·p_y·n_z` |
| line B (`c`), given L and R | | | `c·n_x·p_y·n_z` |

In a unital algebra, set `x = 1`. This works even when `P(1) ≠ 1`, e.g. Theorem 4's fold, which kills every vertex,
because each defect has `x` as a left factor. Item 3 of the summary follows:
- **Line 1 is the one stratum not governed by a module condition.** Its whole defect is `s·n·P(n p)`, and
  ker·P(ker·im) = 0 is strictly weaker than ker·im ⊆ ker. The census has orbits with line 1 but not L
  (pairs_out over 𝔽₃, class RK, two orbits).
- **Point B and line 2 cannot be separated from multiplicativity.** Already D1 at `x = 1` forces both module
  conditions, and by `mult_iff` these say P is an algebra endomorphism. So v2's δ-D2 family (two lines, two points)
  appears exactly for M3 projections: a dendriform reading of M3.

The defect tables were first generated by the symbolic engine of `analysis/completion_generic.py`, then transcribed
into Lean and proved there (`simp` + `module` in the Hodge/Podge decomposition).

## 2. The census by module class

`analysis/module_classes.py` reads the G-orbit representatives of a census (`pcensus.py --save-reps`). For each
representative it computes:
- the classes L (ker·im ⊆ ker), R (im·ker ⊆ ker), K (ker·im·ker = 0) and E (multiplicative);
- the full completion variety in 𝔽_p⁴, exactly, by evaluating the dendriform polynomials at all p⁴ points.

The classes are invariant under conjugation by algebra automorphisms. Hence they are constant on G-orbits, under the
class torus, and on local-torus components; the script asserts the last. It also asserts the Lean predictions on every
orbit, and none failed.

## 3. Extra completions

Some orbits have completions outside the strata of §1. Over 𝔽₃ on 1⇉2⇇3 they are lines again. For example, the 18 LK
orbits each carry the line `x ≻ y = n_x·(p_y + u·n_y)`, line 1 with the opposite sign. These lines come from products
that vanish outright, not merely under P. `analysis/completion_words.py` tests this hypothesis directly:
- For each fold it records which of 18 typed words vanish identically:
  - the 8 words `abc` with a, b, c ∈ {im, ker};
  - the 8 words `P(ab)·c` and `a·P(bc)` with ab, bc mixed;
  - P(ker·im) and P(im·ker).
- It then solves the dendriform equations in the free model where exactly those words are killed.

Result so far: on every orbit of the five censuses tested, the predicted set equals the actual completion variety.

| census | orbits agreeing | distinct vanishing patterns |
|---|---|---|
| 1⇉2⇇3 / 𝔽₃ | 485 / 485 | 25 |
| 1⇇2⇉3 / 𝔽₃ | 485 / 485 | 25 |
| 1⇛2→3 / 𝔽₅ | 120 / 120 | 22 |
| 1⇛2, 1→3 / 𝔽₅ | 207 / 207 | 20 |
| 1⇉2→3→4 / 𝔽₇ | 334 / 334 | 26 |

So in these censuses the completion variety of a fold is a function of its vanishing pattern alone: nonzero words
behave as if free, and no linear relation among them creates a completion. The run over the remaining 16 censuses
(`python3 analysis/completion_words.py` on the dumps in `logs/v2_32/reps.tar.gz`) was cut off with the session turn and
is pending.
